# Hamsters 26.2 Youer 完整移植说明

## 运行环境

- Minecraft 26.2
- NeoForge 26.2.0.59
- Java 25
- GeckoLib 5.5.3 或更高版本（客户端与服务端都必须安装）
- Youer 26.2 混合端

## 已移植功能

- 使用独立仓鼠实体，不再使用兔子实体或普通物品占位。
- 支持驯服、坐下、跟随、繁殖、睡眠、饮水、拾取种子和基础生存 AI。
- 支持 7 种毛色、5 种花纹、染色项圈、脸颊储粮、挤压恢复和脸颊爆裂。
- 支持仓鼠物品捕捉与释放，并保存仓鼠毛色、花纹、项圈、驯服和状态数据。
- 支持 16 色真实仓鼠球实体，可装入、放出仓鼠，滚动、破坏并掉落对应颜色物品。
- 支持笼板、食盆、饮水瓶、仓鼠轮和六向自动连接隧道等完整设施。
- 仓鼠会主动寻找食盆、饮水瓶和仓鼠轮，也会主动拾取掉落的种子。
- 仓鼠轮使用 GeckoLib 动画，仓鼠进入后转动，并输出 15 级红石与比较器信号。
- Create 仅作可选检测，通过红石/比较器读取仓鼠轮状态，不形成硬依赖。
- 恢复原模组 52 个方块资源、物品资源、方块状态和动态实体渲染。
- 自然生成兼容原版温和陆地群系，并兼容已安装群系模组提供的适宜生物群系。

## 服务端配置

首次启动后生成：

`config/hamsters-server.toml`

可配置项目：

- `hamstersSquish`：玩家从上方落下时是否压扁仓鼠。
- `jumpHurtsHamsters`：压扁仓鼠时是否造成伤害。
- `hamstersBurst`：脸颊装满后再次挤压是否触发爆裂。
- `hamsterBurstStyle`：使用彩纸粒子或无方块破坏爆炸表现。
- `naturalSpawnWeight`：仓鼠自然生成权重，设为 `0` 可关闭自然生成。
